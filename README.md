# Ayres Mechanical Website Redesign

Modern Next.js website for Ayres Mechanical Inc.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Motion for React
- shadcn/ui-style components
- Lucide React icons

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production Check

```bash
npm run lint
npm run build
```
